# GAS転記ツール セットアップ手順

Gem「PIAアシスタント」の出力を、自社PIA質問票テンプレ(Google Sheets)へ自動転記する仕組み。
**人の操作は「JSONをコピー → メニューから貼って転記」の1回だけ。**

---

## 全体像

```
Gem出力の <PIA_JSON>…</PIA_JSON>   ←コピー
        │  (人が貼る)
        ▼
マスターテンプレ(Sheets) のメニュー「PIA転記」
        │  GASが実行
        ▼
専用フォルダに PIA_[プロジェクト名]_[日付] を新規生成し、各セルへ転記
```

- Gem と GAS は直接つながりません。橋渡しは人のコピペ1回です。
- マスターは常に空のまま。実行のたびに複製が生成されます(マスターは汚れない)。

---

## 初期セットアップ(1回だけ)

### 手順1: 専用フォルダを用意
生成PIAを入れるフォルダをドライブに作り、URL `…/folders/★` の★部分(フォルダID)を控える。

### 手順2: マスターテンプレにスクリプトを設置
1. PIA質問票テンプレ(Sheets)を開く
2. 拡張機能 → Apps Script
3. `Code.gs` の中身を貼り付け
4. ＋ → HTML → 名前を **`Dialog`** にして `Dialog.html` の中身を貼り付け
5. 保存

### 手順3: CONFIG を自分のテンプレに合わせる
`Code.gs` 冒頭の `CONFIG` を編集(**ここが唯一の調整ポイント**):
- `destFolderId`: 手順1のフォルダID
- `sheets`: 実ファイルのシート名に合わせる
- `scalarGroups`: 項番ラベルの列(labelCol)・回答を書く列(answerCol)を、実テンプレの列構成に合わせる
- `repeaters`: リスク表/アクション表/DPIA判定表の先頭データ行(anchorCell)と相対列
- `dpiaNoneReasonCell`: 「DPIAを実施しない理由」欄のセル

> ※ このコードはテンプレの実レイアウトを見ずに書いた雛形です。列番号・セル座標・シート名は
>   **実ファイルを開いて必ず確認・調整**してください。ここが合っていれば以降は自動です。

### 手順4: 名前付き範囲を作成
テンプレのメニュー「PIA転記 → セットアップ(名前付き範囲を作成)」を1回実行。
- CONFIG の定義から項番ラベルを探し、回答セルに `q_1_1` 等の名前付き範囲を自動生成。
- 「未処理」が出たら、その項番のラベル表記/列設定を CONFIG で直して再実行。
- 以後テンプレの行が増減しても、名前付き範囲がGoogle側で自動追従します(座標ズレ事故なし)。

---

## 毎回の使い方

1. Gem「PIAアシスタント」でPIAを作る
2. 出力末尾の `<PIA_JSON>…</PIA_JSON>` の**中身をコピー**(タグごとでも可)
3. マスターテンプレで「PIA転記 → JSONを貼って転記」
4. ダイアログに貼って「転記」
5. 完了。専用フォルダに生成された新規PIAのリンクが表示される

---

## 挙動のポイント(設計どおり)

- **2段階運用**: `dpia_required=false` なら Section 4〜7 は埋めず、Summary末尾の「DPIAを実施しない理由」に理由だけ記入。
- **残存リスク**: GASはP/I/Mだけ書き、残存はテンプレの数式に計算させる(色分けも維持)。Gemの`residual`は検算に使い、食い違えば警告。
- **可変行**: リスク/アクションは必要行数だけ自動で行挿入(書式・数式コピー)。
- **バリデーション**:
  - ハードエラー(JSON崩れ / jurisdiction欠落 / dpia_required非真偽)→ **転記中止**
  - ソフト警告(未知の項番キー / 残存の乖離 / 段階矛盾)→ 一覧表示のうえ続行/中止を選択
  - 生成ファイルに `_転記ログ` タブ(日時・JSONハッシュ・警告一覧)を残す
- **命名衝突**: 同名があれば `_v2`, `_v3` を自動付与(上書きしない)。
- **プロジェクト名未設定**: `PIA_未設定_[日付]_[時刻]` の暫定名で保存。

---

## 権限について
初回実行時、GASがドライブ(複製・フォルダ配置)とスプレッドシート編集の承認を求めます。一度承認すれば以後は自動です。
